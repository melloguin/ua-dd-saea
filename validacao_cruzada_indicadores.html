Validação cruzada de máquinas — fronts e indicadores

Quatro máquinas rodaram as mesmas células (exp=main, semente 42). Os dados brutos divergem nas configs Python; a pergunta é se os indicadores divergem junto. Tag de cada série: vm / experimento / algoritmo / problema / semente.

1 · Fronts não-dominados

Objetivos normalizados por (ideal, nadir) da tabela S.5 (D69) — a mesma base para todas as máquinas. Pontos sobrepostos = fronts idênticos.

2 · Convergência — hipervolume × avaliações reais

HV do conjunto não-dominado acumulado, ref = 1,1 por coordenada no espaço normalizado (D69/D92). 25 checkpoints por célula.

3 · Dispersão do HV entre máquinas

Eixo comum: desvio percentual do HV em relação à média das máquinas daquela célula — os comprimentos são comparáveis entre linhas. Cada ponto é uma máquina; a barra cinza é a amplitude. O losango vazado, onde existe, é a mesma célula com outra semente (semente 0, no Mac): a régua do ruído que o estudo já aceita.

IGD+ é o endpoint primário do estudo (D70). Spacing de Schott (L1) mede uniformidade — menor é mais uniforme.
