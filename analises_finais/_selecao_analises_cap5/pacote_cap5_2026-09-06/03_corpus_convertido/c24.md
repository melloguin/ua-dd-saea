# **A Numerically Efficient Multi-Objective Optimization Algorithm: Combination of Dynamic Taylor Kriging and Differential Evolution** 

Bin Xia<sup>1</sup> , Nyambayar Baatar<sup>2</sup> , Ziyan Ren<sup>1,3</sup> , and Chang-Seop Koh<sup>1</sup>

**A dynamic Taylor Kriging (DTK) is newly developed and combined with a multi-objective differential evolution algorithm to get a numerically efficient multi-objective optimization strategy. In the DTK, basis functions are not predefined but optimally selected so that the fitting error with the given sampling data may be minimized. In the developed multi-objective optimization algorithm, the DTK provides predicted objective function values as an alternative to direct finite-element analysis. The effectiveness of the proposed DTK and multi-objective optimization strategy are verified through applications to analytic example and TEAM 22.** 

**_Index Terms_ —Binary particle swarm optimization (B-PSO), dynamic Taylor Kriging (DTK), multi-objective differential evolution (MODE).** 

## I. INTRODUCTION 

HE optimization of engineering problems often involves **T** multiple objectives, which need to be optimized simultaneously. Thus, the multi-objective optimal design is an important research topic. Recently, several multi-objective evolutionary algorithms have been developed and successfully applied to the design of numerous engineering applications [1], [2]. Differential evolution (DE) has been reported to be a simple yet a powerful optimization algorithm and successfully applied to single and multi-objective optimization problems [3]. However, the DE algorithm, similar to other evolutionary ones, requires a large number of objective function evaluations since it needs a set of objective function values in each iteration to find a set of non-dominated solutions, i.e., Pareto-optimal solutions in a feasible region. This often limits its application to engineering problems through direct combination with finite-element analysis (FEA) [4], [5]. 

Recently, surrogate models, such as Kriging and neural network meta-models, have been developed and widely used to facilitate the optimization of engineering problems, which otherwise involve computationally expensive simulations such as non-linear FEA. Kriging meta-models, especially, are attracting much attention because they provide both global prediction and local flexibility [5]. However, their fitting accuracy (or prediction accuracy) strongly depends on the problem and also the selection of basis functions. Recently, dynamic Kriging, which optimally selects its basis functions so that its fitting error is minimized, has been suggested in the field of mechanical engineering [6]. 

In this paper, a dynamic Taylor Kriging (DTK), which optimally selects its basis functions among all possible ones using a binary particle swarm optimization (B-PSO) algorithm, is proposed to get a higher fitting accuracy even with a relatively small number of sampling data, and 

applied to a multi-objective optimization of engineering problem through combination with a multi-objective differential evolution (MODE) algorithm.

## III. MODE ALGORITHM ASSISTED BY DTK 

In a multi-objective optimization, a Pareto-front, i.e., the collection of non-dominated solutions, which has a crowding distance as uniform as possible and a good quality of extreme solutions is to be found instead of a single global optimum solution as in a single-objective optimization. 

For this, in this paper, a MODE algorithm, suggested in [10] and [11], is combined with the developed DTK. The MODE algorithm incorporates: 1) non-dominated ranking for maintaining population diversity; 2) multi-guiders for enhancing the quality of Pareto-front; and 3) an improved pruning method to keep the crowding distance as uniform as possible. 

During the optimization process, the objective function and constraint values are predicted using the DTK instead of the direct calculation using FEA.

A. Construction of DTK
1. Initial sampling points
• Generate Ninit sampling points using the LHD, and

• For all sampling points, calculate the objective function
and constraint function values using FEA.
• Find the best combination of basis functions using the
B-PSO algorithm, and construct the DTK.
• Calculate d(x) for all NTS test points, and if the
max{d(x)} ≤ε, then terminate stage A and go to stage B.
3. Adaptive sampling
• Select Nstep test points in the order of their d(x), and
insert them into the set of sampling points.
• Go to Step 2.
B. DTK assisted MODE
1. Initialize
• Generate the target population, and evaluate their objec-
tive functions and constraint functions values using the
DTK.
• Rank all individuals, and calculate the crowding distance
in each rank.
2. Select guiders and generate mutant population
• Select the ﬁrst guider g1 randomly, and select second one
g2 if the ﬁrst one is not an extreme solution
• Generate the mutant population using the guiders.
3. Crossover and selection
• Generate a trial vector using the binominal crossover.
• Select the population among the target and trial vectors
in the feasible region for next iteration.
• If the population in the feasible region is not enough,
select the rest from the infeasible region in the reverse
order of their sum of constraint violation.
4. Update non-dominated solutions and parameters
• If the number of non-dominated solutions exceeds its pre-
deﬁned maximum, remove the excess in the reverse order
of their crowding distance.
• Update the mutant factor and crossover rate.
5. Termination check
• If termination condition suggested in [10] is not satisﬁed,
go to Step 2; otherwise terminate the algorithm.

V. CONCLUSION
A DTK is proposed and combined with a MODE algorithm
to develop a numerically efﬁcient multi-objective optimization
algorithm. In the algorithm, the DTK plays a role as an
alternative to numerically expensive FEA, and it is proven
to give a higher modeling accuracy than any other Kriging,
such as OK, UK, and TK. A guideline on the proper num-
ber of sampling points is also suggested by introducing the
bandwidth of prediction interval. The proposed optimization
algorithm, DTK-assisted MODE algorithm, is also proven to
give a Pareto-optimal solutions as good as those obtained
direct combination with FEA through an application to the
multi-objective version of TEAM 22 with eight parameters.
