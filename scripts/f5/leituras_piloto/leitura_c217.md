## A. FICHA DO MECANISMO (do artigo)

Fonte: Tian et al., *SWEVO* 80:101323 (2023), Algoritmos 1–6, §3.1–§3.4, §4.1. Laço central (1 iteração = 1 geração externa):

1. **Init**: P ← 11d−1 soluções por LHS, avaliadas no real; `Arc ← P` (arquivo externo de TODAS as avaliações reais); FE ← 11d−1 (Alg. 1, L1–4; §3.1).
2. **Fitness (Eq. 4)**: `fitness(x) = r·Σ_{y∈Sx}|R_y| + (1−r)·1/(SDE(x,x′)+2)`, com r = FE/FEmax (annealing convergência↔diversidade), SPEA2-raw como termo de convergência, SDE (Eq. 5) ao ⌊√N⌋-ésimo vizinho como densidade; menor = melhor (§3.2). *(A equação sobrevive só na análise do agente-4 — o markdown do paper perdeu as imagens das Eqs. 1–5.)*
3. **SampleSelection (Alg. 2)**: Pbest = ⌈|P|/4⌉ melhores, Pworst = ⌈|P|/4⌉ piores pelo fitness da Eq. 4.
4. **DataGeneration (Alg. 3)**: 3/4 aleatórios de Pbest/Pworst → treino; 1/4 restante → validação. Treino: cada x∈Pbest^train × cada y∈Pworst^train → ⟨x,y,1⟩ e ⟨y,x,0⟩ (2×(3N/16)² amostras, classes balanceadas por construção). Validação: cada x∈Pbest^valid pareado sem reposição com y∈Pworst^valid → ⟨x,y,1⟩.
5. **Modelo substituto (§3.1, Eqs. 2–3)**: PNN (Specht) par-a-par; entrada = concatenação [x;y] (2d), saída = rótulo binário "x é melhor". Φ gaussiana com **σ=0,2** (paper); sem treino iterativo (determinístico dado o conjunto); **retreinado do zero a cada geração** (Alg. 1 L8); treino <10% do runtime (§4.4).
6. **Validation → incerteza (Alg. 4, §3.3)**: para cada par de validação, prediz ⟨x,y⟩ E ⟨y,x⟩; p⁺ = fração consistente-e-certa, p⁻ = fração consistente-e-invertida; rótulos iguais = contradição. Regra tripla com **δ=0,8** (§4.1, Fig. 8): p⁺>δ → *state 1* (usar direto); p⁻>δ → *state 2* (usar INVERTIDO — erro sistemático é recuperável); senão *state 3* (ignorar — erro aleatório). É a gestão de incerteza do algoritmo (confiabilidade agregada do modelo, não σ por ponto).
7. **Generation (Alg. 5)**: Q←P; até **Gmax=3000 predições** ("maximum number of surrogate predictions", Input do Alg. 1 — o loop escrito "for gen=1..Gmax" é ambíguo; o código resolve como wmax=⌊Gmax/lnum⌋ gerações internas): variação SBX+PM sobre Q∪Pbest, **score(x) = out⟨x,y⟩ − out⟨y,x⟩** com y sorteado de Pbest por candidato (Alg. 6); state 1 mantém os |Pbest| de maior score e acumula em AllQ os com **score>0,95**; state 2 espelha (menor score; score<−0,95); state 3: UMA variação e **1 candidato aleatório**.
8. **Infill**: "at most six" de AllQ com maior (state 1) / menor (state 2) score, ou 1 aleatório (state 3) → avaliação real, `Arc ← Arc ∪ Q`, FE += |Q| (Alg. 1 L11–14, Alg. 5 L10/18/21).
9. **Seleção ambiental**: P ← min{N,|Arc|} soluções do Arc pela seleção do SPEA2 (Alg. 1 L13). Repete até FE>FEmax; saída = Arc.
10. **Parâmetros do paper (§4.1)**: N=50, FEmax=2000, Gmax=3000, δ=0,8, σ_PNN=0,2, SBX pc=1/PM pm=1/d com índice de distribuição **20**, init 11d−1 LHS, 30 runs, IGD com ~10k pontos de referência, Wilcoxon 0,05.
