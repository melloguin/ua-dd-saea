# handoff/ — continuidade entre sessões

1 arquivo por sessão de implementação (`handoff/{CARTAO}.md`), escrito ao FIM de cada sessão:
o que foi feito, arquivos tocados, resultado do teste de aceitação, pendências.
**A próxima sessão começa lendo o handoff/ da anterior** (regra 1-sessão-1-cartão, D83).
